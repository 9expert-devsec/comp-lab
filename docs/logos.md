# คู่มือไฟล์โลโก้

วางไฟล์โลโก้ไว้ใน `public/logos/` ตามโฟลเดอร์ด้านล่าง เว็บไซต์อ่านโฟลเดอร์เหล่านี้ตอน build
เพิ่มหรือลบไฟล์แล้วต้อง build ใหม่ ไม่ต้องแก้โค้ดของหน้าเว็บ

## โฟลเดอร์และส่วนที่ใช้

| โฟลเดอร์ | ใช้ในส่วน | สถานะ |
|---|---|---|
| `public/logos/clients/` | Hero (แถบโลโก้ลูกค้า แสดงชุดละ 6 โลโก้) | ใช้งานจริงแล้ว |
| `public/logos/government/` | Web Accessibility (#accessibility) แถว "หน่วยงานภาครัฐที่ให้ความไว้วางใจ" | ใช้งานจริงแล้ว (ถ้าโฟลเดอร์ว่าง จะแสดงกล่อง placeholder) |
| `public/logos/platforms/` | แพลตฟอร์ม (#platforms) โลโก้บนดาวเคราะห์ | ใช้งานจริงแล้ว |
| `public/logos/brand/` | แพลตฟอร์ม (#platforms) สัญลักษณ์ 9Expert บนดาวเคราะห์ด้านข้าง | ใช้งานจริงแล้ว (ยังไม่มีไฟล์) |

โลโก้ 9Expert ใน Header/Footer ยังอยู่ที่ `public/images/`

## โลโก้ลูกค้าและหน่วยงานรัฐ (clients/, government/)

1. ตั้งชื่อไฟล์ `NN-ชื่อย่อ.png` เช่น `43-toyota.png`
   - **`NN-` คือลำดับการแสดงผล** (เรียงตามชื่อไฟล์) ใช้เลขสองหลัก 01, 02, …
   - ชื่อย่อเป็น **kebab-case** ภาษาอังกฤษตัวพิมพ์เล็ก ห้ามมีช่องว่าง ภาษาไทย หรือตัวพิมพ์ใหญ่
2. **เพิ่มชื่อองค์กร 1 บรรทัด** ใน `src/data/logo-names.js` ใต้ `clients` หรือ `government`
   โดยใช้ชื่อย่อ (ไม่มี `NN-` และนามสกุลไฟล์) เป็น key เช่น `toyota: "Toyota",`
   - ใช้ชื่อทางการขององค์กร องค์กรไทยใช้ชื่อภาษาไทย เช่น `bot: "ธนาคารแห่งประเทศไทย",`
   - ชื่อนี้คือข้อความ alt ที่โปรแกรมอ่านหน้าจออ่านออกเสียง
   - ถ้าลืมเพิ่ม build จะไม่ล้ม แต่จะขึ้นคำเตือน `[logos] No name for …` และใช้ชื่อไฟล์แทน
3. รูปแบบไฟล์
   - **PNG หรือ WebP พื้นหลังโปร่งใส** (รองรับ SVG ด้วย)
   - **กว้างอย่างน้อย 400px**
   - **ตัดขอบว่างรอบโลโก้ออกให้ชิดที่สุด** ทุกโลโก้จะถูกย่อให้พอดีกล่องขนาดเท่ากัน
     ถ้ามีขอบว่างมาก โลโก้จะดูเล็กกว่าโลโก้อื่น

## โลโก้แพลตฟอร์ม (platforms/, brand/)

ดาวเคราะห์มีพื้นสีน้ำเงิน (ตรงกลาง) และสีกรมท่า (ด้านข้าง) จึงต้องใช้ **โลโก้สีขาวล้วนบนพื้นโปร่งใส**
ไฟล์ที่ไม่มีพื้นโปร่งใสจะถูกข้ามตอน build (แสดงข้อความแทน) เพื่อไม่ให้เห็นเป็นสี่เหลี่ยมสีขาว

| แพลตฟอร์ม | slug | ไฟล์สีขาว (ใช้บนดาวเคราะห์) | ไฟล์สีเต็ม |
|---|---|---|---|
| 9Expert Training | `training` | `platforms/training-white.png` | `platforms/training.png` |
| 9Expert Masterclass | `masterclass` | `platforms/masterclass-white.png` | `platforms/masterclass.png` |
| 9Expert Career Path | `career-path` | `platforms/career-path-white.png` | `platforms/career-path.png` |
| 9Expert Academy | `academy` | `platforms/academy-white.png` | `platforms/academy.png` |
| Thai Web Accessibility | `twa` | `platforms/twa-white.png` | `platforms/twa.png` |

- ดาวเคราะห์ทุกดวง (ตรงกลางและด้านข้าง) ใช้ไฟล์ `<slug>-white.png` ของแพลตฟอร์มนั้น
  ถ้ายังไม่มี ดาวเคราะห์ตรงกลางแสดงชื่อย่อ (เช่น "Training")
  ส่วนดาวเคราะห์ด้านข้างใช้สัญลักษณ์ 9Expert สีขาว `brand/9expert-mark-white.png`
  และถ้ายังไม่มีไฟล์นั้นด้วย จะแสดงตัวเลข "9" สีฟ้า
- ขนาด: กว้างอย่างน้อย 400px พื้นโปร่งใส ตัดขอบว่างออก
- เพิ่มแพลตฟอร์มใหม่ (เช่น Exam) ได้ที่ `src/data/platforms.js` แล้ววางไฟล์ `<slug>-white.png` ตาม slug ที่ตั้ง
